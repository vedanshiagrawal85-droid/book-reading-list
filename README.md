# Book Reading List Application

A responsive web application designed for organizing your reading journey, tracking finished books, maintaining a reading wishlist, and tracking reading goals.

## Features
- **Book Management**: Add, view, and delete books.
- **Status Categorization**: Mark books as *Currently Reading*, *Completed*, or *Wishlist*.
- **Local Storage Persistence**: Books stay saved in your browser even after refreshing.
- **Search & Filter**: Quickly filter books by status or title.

## How to Run
Open `index.html` in your web browser.
